⚙ ETL Pipeline Overview
How data flows from public clinical sources into the warehouse — as implemented in warehouse_etl.py.
📥

Extract

HTTP requests to clinical sources using BeautifulSoup. Parses all <img> tags and downloads JPEG images per source per cancer type.

⚗

Transform

Images decoded with OpenCV, converted to grayscale (COLOR_BGR2GRAY), and uniformly resized to 224 × 224 px.

🗄

Load

Processed images saved to SkinWarehouse/ with structured filenames. Metadata inserted into MySQL FactLesions table.

📤

Export

Full warehouse snapshot exported to CSV and HTML via pandas for analysis and presentation.

🗂 Database Schema
The SkinCancerDW MySQL schema — single fact table, star-schema ready.
📄 Creation SQL
CREATE DATABASE SkinCancerDW;
USE SkinCancerDW;

CREATE TABLE FactLesions (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    SourceURL   VARCHAR(700),
    Label       VARCHAR(50),
    LocalPath   VARCHAR(500),
    CreatedDate TIMESTAMP
                DEFAULT CURRENT_TIMESTAMP
);

🏥 Cancer Type Reference
Clinical summaries of the three cancer categories tracked in this warehouse.
🔬
Melanoma MEL

Develops in melanocytes (pigment cells). Most dangerous form of skin cancer; can metastasise if not caught early.

🔬
Basal Cell Carcinoma BCC

Most common skin cancer worldwide. Slow-growing; rarely spreads but can cause significant local tissue damage.

🔬
Squamous Cell Carcinoma SCC

Second most common. Arises from squamous cells in the outer skin layers. More likely to spread than BCC.
