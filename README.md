# Skin Cancer Detection Data Warehouse

A clinical image data warehouse for **Melanoma (MEL)**, **Basal Cell Carcinoma (BCC)** and **Squamous Cell Carcinoma (SCC)** — featuring an automated ETL pipeline, MySQL backend, and a premium interactive web dashboard.

## Project Structure

```
SkinCancerDWM/
├── index.html              # Dashboard frontend
├── style.css               # Dark medical-grade UI theme
├── app.js                  # Frontend logic (live API data fetch)
├── server.py               # Flask backend (MySQL API + static serving)
├── warehouse_etl.py        # ETL pipeline (scrape → transform → load)
├── requirements.txt        # Python dependencies
├── .env.example            # Environment variable template
├── setup.bat               # One-click setup (Windows)
├── start.bat               # One-click server launch (Windows)
├── SQL/
│   ├── 1. Creation.sql     # Database + table schema
│   └── 2. Selection.sql    # Sample queries
└── SkinWarehouse/          # Warehouse images (generated by ETL)
```

## Quick Start (Any PC)

### 1. Prerequisites
- **Python 3.10+** — [python.org/downloads](https://www.python.org/downloads/)
- **MySQL Server** running locally — [dev.mysql.com/downloads](https://dev.mysql.com/downloads/mysql/)

### 2. Clone the repo
```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>/SkinCancerDWM
```

### 3. Configure credentials
```bash
# Copy the template and edit with your MySQL details
copy .env.example .env
notepad .env
```

Fill in your values:
```
DB_HOST=localhost
DB_USER=your_mysql_username
DB_PASSWORD=your_mysql_password
DB_NAME=SkinCancerDW
PORT=8080
```

### 4. One-click setup (Windows)
```bash
setup.bat
```
This creates the virtual environment and installs all dependencies.

### 5. Run the ETL pipeline (first time only)
```bash
.\venv\Scripts\python.exe warehouse_etl.py
```
This scrapes images, transforms them, and populates MySQL.

### 6. Launch the dashboard
```bash
start.bat
```
Then open your browser at **http://localhost:8080**

## Manual Setup

```bash
# Create venv
python -m venv venv

# Activate (Windows)
.\venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run ETL (populate database)
python warehouse_etl.py

# Start server
python server.py
```

## API Endpoints

| Endpoint | Description |
|---|---|
| `GET /api/records` | All records from `FactLesions` (MySQL → CSV fallback) |
| `GET /api/stats` | Label counts + source distribution |

---

## Database Schema

```sql
CREATE TABLE FactLesions (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    SourceURL   VARCHAR(700),
    Label       VARCHAR(50),     -- MEL | BCC | SCC
    LocalPath   VARCHAR(500),
    CreatedDate TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## Notes
- `SkinWarehouse/` images are **not committed** to git (`.gitignore`) — run the ETL on each machine to regenerate them.
- The server **auto-falls back to CSV** if MySQL is unavailable, so the dashboard always shows data.
- Default MySQL credentials (`curious`/`toor`) are hardcoded as fallbacks in `.env.example` — override with your own.
